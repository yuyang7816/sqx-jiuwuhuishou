# 旧物回收用户端

## 开源说明

本项目仅开源 uni-app 用户端，基于 Vue3，适配电脑/手机网页、微信小程序等。用 HBuilderX 导入本目录即可运行，供学习研究。

## 能在哪些地方使用

需要预约旧物上门回收或顺丰寄件回收的家庭用户，可以在电脑或手机的网页里使用，也可以在微信小程序里使用。同一套用户端里，平台员工（回收员）也可以查看取件任务、上门取件并回填成交金额。

底部有四个主入口：**首页、福利中心、订单、我的**。

## 对接了哪些第三方

下面这些是用户日常能直接感受到的外部服务，不是技术名词堆砌：

- **省市区选择**：新增常用地址时，可选择省市区并填写详细门牌信息，方便上门取件或预约寄件。
- **微信支付**：开通会员等需要付款时，在微信小程序或 App 里可走微信支付。普通电脑浏览器网页一般不出现微信支付。
- **钱包余额**：平台自己的余额账户；回收打款、佣金提现、积分兑换等会进钱包；可再申请提现到微信或支付宝。
- **微信 / 支付宝提现**：账户余额提现时，可选择微信收款码或支付宝账号收款。
- **手机短信验证码**：注册、找回密码时，会往手机发验证码（由服务端发送）。
- **微信一键登录**：在微信小程序里，可先微信授权，再授权手机号完成登录。
- **顺丰寄件**：部分品类可选「顺丰包邮」寄往平台质检；订单里可看运单号与物流轨迹。
- **平台在线客服**：登录后可在客服中心与平台客服即时发消息。
- **电话**：订单详情可联系回收员；员工端可拨打用户电话确认上门。
- **手机系统能力**：从相册选头像/收款码、保存邀请海报、复制邀请链接/订单号、拨打电话、分享邀请等。

说明：具体支付渠道、短信、快递是否真正可用，取决于线上后台是否已配置对应账号；开源学习时，页面按钮一般都能看到，部分第三方能力可能点了没反应。

## 游客能做什么

下面说的「游客」，指还没登录账号的人。能看的内容很多；涉及下单、签到领奖、提现、邀请等，会提示先登录。

### 打开软件先看到什么（首页）

- 顶部展示品牌名「旧物回收」。
- 可开启推送提醒条（文案以后台配置为准，例如回收进度提醒）。
- 有轮播广告图，点进去可跳到旧衣、数码估价、推荐分佣等页面（具体以后台配置为准）。
- 有滚动公告，展示近期回收成交类提示。
- 有一排品类入口（例如家电回收、数码回收、旧衣回收、奢侈品、书籍等，名称和跳转以后台配置为准）。
- **推荐赚钱横幅**：引导进入推荐分佣规则或邀请页。
- **任务入口**：如每日签到、环保红包、品牌合作、家电维修咨询等（以后台配置为准）。
- 右下角可进入在线客服。

### 看品类、估价与预约

- 进「家电回收」：选品类 → 选品牌型号与成色参数 → 看预估价 → 进入估价结算。
- 进「数码回收 / 奢侈品」：搜索或选择机型规格，按参数估出参考价后再下单。
- 进「旧衣回收 / 书籍」：看回收单价与可回收品类，选地址、预约时段、预估重量，看预估金额。
- 可查看服务范围与价格规则；真正提交回收订单一般需要登录。

### 上门回收、顺丰寄件

- 家电等品类在「估价结算」可选履约方式：
  - **上门回收**：选服务城市、取件地址、上门时段后提交。
  - **顺丰寄件**：按平台收件信息寄出（顺丰包邮说明以页面为准），寄出后可在订单中查看物流。
- 下单成功页可分享邀请好友一起参与回收。

### 福利中心（底部「福利中心」）

- 查看我的积分 / 金币、连续签到天数。
- 每日签到领金币；可开关连续签到奖励。
- 做福利任务（如邀请好友、发布回收等，以后台配置为准）。
- 积分可按规则提现到钱包（需登录）。

### 怎么收款、怎么付会员（登录后）

- 回收成交确认后，平台按打款流程把钱打到用户账户；可在订单里看「打款进度」。
- 推荐佣金、积分兑换也会进入「账户余额」。
- 「我的」里可看余额明细，再申请提现到 **微信** 或 **支付宝**。
- 开通会员时，按当前打开环境走支付（常见为微信支付）；开通后可享优先上门、专属客服、加价回收等权益（以会员页说明为准）。

### 订单里能看到什么（登录后）

- 底部「订单」按状态筛选：**全部、进行中、待确认、已完成**。
- 订单详情里有：订单状态、订单编号、回收品类、履约方式（上门 / 邮寄）、预约时间、地址、预估与实际成交金额、服务进度时间线。
- 邮寄订单可看快递公司、运单号、物流轨迹，并按需填写发货信息。
- 进行中可改约、异常反馈、取消订单；上门单可「联系回收员」。
- 待确认时可进入「结算确认」（接受成交价或发起价格争议）。
- 完成后可「评价投诉」，并可查看「打款进度」。

### 积分、钱包、会员、推荐（登录后）

- 「福利中心」签到领金币，并查看积分明细。
- 「我的」账户余额：看余额、预估待入账、环保积分。
- 「我的推荐 / 邀请好友」：生成邀请海报与链接，看邀请记录与分佣说明；佣金可提现到钱包。
- 「会员中心」看专属权益，选套餐后付款开通。

### 账号、地址、客服

- **网页 / App**：手机号 + 密码登录；未注册可走注册（短信验证码）；可找回密码。
- **微信小程序**：微信快捷登录 → 再授权手机号。
- 登录前需同意《用户协议》《隐私政策》。
- 「我的」里可改头像、昵称等资料；可进个人设置。
- **常用地址**：新增 / 编辑上门或取件地址（省市区、详细地址、家/公司等标签、是否默认）。
- **消息通知**：在设置里可开关消息通知；通知列表可查看系统消息。
- **帮助 / 客服中心**：看常见问题；可进「在线客服」聊天（需登录）。
- **系统设置**：修改登录密码、清理缓存、关于我们、协议、退出登录等。
- **品牌合作**：可查看联名 / 合作相关入口（以后台与页面配置为准）。

### 员工取件入口

- 员工账号（用户类型为员工）在「我的」底部会出现「我的取件」。
- 普通用户看不到该入口；游客点相关能力会先要求登录。

---

## 员工（回收员）能做什么

员工账号登录后，「我的」会出现「我的取件」，主要能力如下：

- **今日取件任务**：按待上门、取件中、已完成查看任务数量与列表。
- **取件详情**：看回收品类、联系人、预约时间、取件地址与取件流程。
- **开始上门 / 确认完成取件**：按任务状态推进；完成时可回填实际成交金额（作为用户侧成交与后续打款依据）。
- **联系用户**：可拨打电话确认地址与时间。

说明：员工账号由后台分配，用户端不提供「公开入驻申请」流程。

## 运行

这份代码已经接到线上体验环境，**不用改任何配置，打开后直接运行即可。**

### 开始前请准备

1. 一台 Windows 电脑（苹果电脑也可以，步骤差不多）。
2. 下载并安装 **HBuilderX**（官方用来打开这类项目的软件）：  
   打开浏览器，搜索「HBuilderX 官网」，进入 [https://www.dcloud.io/hbuilderx.html](https://www.dcloud.io/hbuilderx.html)，下载「正式版」，安装后打开。
3. 建议再装一个 **Chrome 浏览器**，用来打开运行后的页面。

### 第一步：拿到文件夹

1. 如果你收到的是压缩包（例如 zip），先右键「解压到当前文件夹」或「解压到指定文件夹」。
2. 解压后，请找到名字叫 **`vue3+uviewPlus`** 的文件夹。里面应该能看到 `pages.json`、`App.vue`、`common`、`pages` 等文件和目录。
3. 记住这个文件夹在电脑上的位置，后面要选中它。不要只打开里面某一个文件。

### 第二步：用 HBuilderX 打开整个项目

1. 打开已经安装好的 HBuilderX。
2. 点左上角 **「文件」→「打开目录」**（有的版本也叫「从本地打开」）。
3. 选中刚才的 **`vue3+uviewPlus`** 文件夹，确定。
4. 左侧出现一长串文件名，就说明打开对了。如果左侧是空的，说明选错了文件夹，请重新选带 `pages.json` 的那一层。

### 第三步：用浏览器运行

1. 在 HBuilderX 顶部菜单点 **「运行」→「运行到浏览器」→「Chrome」**。
2. 第一次可能会提示安装浏览器运行插件，点允许或安装，等它装完再重新点一次运行。
3. 电脑会自动弹出一个网页。出现首页、底部「首页 / 福利中心 / 订单 / 我的」，就说明运行成功了。
4. 如果浏览器问能不能获取位置，点「允许」（本项目以地址与服务城市选择为主，不影响大部分页面浏览）。
5. 不要关 HBuilderX，关了网页可能会断开。

### 常见情况说明

- **点了运行没反应**：确认打开的是整个 `vue3+uviewPlus` 文件夹，不是只打开了一个页面文件。
- **浏览器打开了但是花屏、一直转圈**：等十几秒；仍不行就关掉网页，在 HBuilderX 里再点一次运行。
- **页面是空的、提示加载失败**：检查电脑能否打开体验地址 https://jwhs.xianmxkj.com ；如果这个网页本身打不开，用户端也会没数据。
- **定位失败或选不了地址**：可先手动选择省市区并填写详细地址；学习看页面时不影响浏览。
- **微信支付、提现点了没反应**：需要商家自己的支付 / 商户账号，这份开源代码一般只能看到按钮，不能真的完成收款或打款（或仅部分环境可用）。
- **短信验证码收不到、在线客服无回复、顺丰下单失败**：这些依赖服务端和第三方账号，界面可以点，功能不一定通。
- **想跑微信小程序**：需安装「微信开发者工具」，在 HBuilderX 里选「运行到小程序模拟器 → 微信开发者工具」，并在 `manifest.json` 里使用你自己的小程序 AppID。

### 第一次建议怎么验收

1. 按第三步在 Chrome 打开。
2. 能看到首页轮播或品类入口、底部四个按钮（首页 / 福利中心 / 订单 / 我的）。
3. 点「福利中心」，能看到签到或积分相关内容（未登录可能提示登录，也算正常）。
4. 点「我的」，能看到登录入口或个人中心。
5. 再点「订单」，能进入订单页（未登录可能提示登录，也算正常）。  
做到这里，就说明「这份用户端代码已经在你电脑上跑起来了」。
