# 服务端运行教程

按顺序做。做完一步，看到文中写的成功标志，再做下一步。

服务端是三个端里要第一个启动的。它没有给预约回收的人点的页面。手机上的「旧物回收」和电脑上的「旧物回收管理后台」把登录、估价、下单这些动作发给它。它负责检查是否允许，并把结果记进数据库。

代码在 `jiuwuhuishou-server` 文件夹。回收业务的建表和后续变更在 `jiuwuhuishou-server/sql`，文件名从 `V1__recycle_init.sql` 排到后面的版本。这些脚本不会自己创建数据库，也不会单独交出一套管理员、角色、菜单的完整系统库。

整个项目文件夹里应能同时看到这三个名字：`jiuwuhuishou-server`、`jiuwuhuishou-admin`、`jiuwuhuishou-user`。下面说的「项目根目录」就是这一层。

## 开始之前要准备什么

在自己的 Windows 电脑上安装下面三个软件。安装时勾选「添加到 PATH」或「Add to PATH」。

| 软件 | 用什么版本 | 它是干什么的 | 怎样确认已经装好 |
|---|---|---|---|
| JDK | 1.8（也叫 Java 8） | 运行服务端的语言环境 | 开始菜单打开 PowerShell，输入 `java -version`，能看到 `1.8.0` |
| Maven | 3.6 或更高 | 下载服务端需要的程序包，并把它启动起来 | 输入 `mvn -v`，能看到 `Apache Maven 3` |
| MySQL | 8.0 | 存放品类、订单、用户、钱包这些数据 | 开始菜单里能找到「MySQL 8.0 Command Line Client」 |

Java 请安装 1.8。装成 11、17 或 21 时，这个项目编译或启动会失败。下载可用 Adoptium 的 Temurin 8：https://adoptium.net/temurin/releases/?version=8

Maven 下载：https://maven.apache.org/download.cgi 。解压后把里面的 `bin` 文件夹加到 PATH。关掉原来的 PowerShell，再打开一个新的，`mvn -v` 才能看到版本。

MySQL 安装过程中会让你给 `root` 设一个密码，还会让你确认端口。把密码和端口记下来。Windows 上新装的 MySQL，端口通常是 **3306**。开发配置里写的用户名是 `root`，密码是 `root`。你安装时设的密码如果不是 `root`，后面改配置时把密码改成你自己的。

这个项目本地默认不使用 Redis。`application.yml` 里 `sqx.redis.open` 是 `false`。先把 MySQL 和 Java 准备好即可，不必为了第一次启动再去装 Redis。

## 第 1 步：确认 MySQL 能登录

1. 打开开始菜单里的 MySQL 命令行。
2. 输入你安装 MySQL 时设的 root 密码，回车。看到 `mysql>` 才算连上。
3. 输入 `exit` 退出。

如果提示 `Access denied`，是密码错了，用安装时设的那个密码重来。后面导入和改配置，都用这同一个密码。

## 第 2 步：新建数据库并导入脚本

开发配置里的库名是 `jiuwuhuishou`。脚本自己不会创建这个库。请先建库，再按版本号导入。

在 `mysql>` 里执行：

```sql
CREATE DATABASE IF NOT EXISTS jiuwuhuishou DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
exit
```

然后在 PowerShell 里进入 `jiuwuhuishou-server`，按文件名里的版本数字从小到大导入。密码不是 `root` 时，把 `-proot` 改成你的密码，`-p` 和密码之间不要空格。

```powershell
cd jiuwuhuishou-server
Get-ChildItem .\sql\V*.sql | Sort-Object { [int]($_.Name -replace '^V(\d+).*','$1') } | ForEach-Object {
  Write-Host $_.Name
  cmd /c "mysql -uroot -proot --default-character-set=utf8mb4 jiuwuhuishou < `"$($_.FullName)`""
}
```

看到每一份脚本的文件名依次打印，并且没有 `ERROR`，这一步就完成了。

这批脚本负责回收地址、品类、订单、福利、钱包等业务表。管理员、角色、菜单这类系统表不在这里。空库只做完这一步时，后台的 `admin` 账号还不存在，管理端会登不进去。系统表需要沿用你已经有的库，或按项目里系统模块的表结构另行准备。

## 第 3 步：改成开发环境，并核对数据库

用记事本或编辑器打开：

`jiuwuhuishou-server/sqx-application/src/main/resources/application.yml`

找到：

```yaml
spring:
  profiles:
    active: prod
```

把 `prod` 改成 `dev`，保存。`prod` 会去连线上库。本地练习必须用 `dev`。

再打开同目录的 `application-dev.yml`。数据源应类似：

```yaml
url: jdbc:mysql://127.0.0.1:3306/jiuwuhuishou?...
username: root
password: root
```

库名保持 `jiuwuhuishou`。MySQL 密码不是 `root` 时，只改 `password`。端口不是 3306 时，把 `3306` 改成你的端口。

同一份 `application.yml` 里，服务端口是 **9135**，访问路径是 `/sqx_fast`。没有特殊需要时不要改端口。

`sqx.verify-code.test-mode` 现在是 `true`，短信验证码固定为 `888888`。本地注册、找回密码可以用这个码。准备正式发短信时，再改成 `false`，并在管理端填短信密钥。

## 第 4 步：启动

在 `jiuwuhuishou-server` 文件夹打开 PowerShell，执行：

```powershell
mvn -pl sqx-application -am spring-boot:run
```

第一次会下载依赖，可能要几分钟到十几分钟。成功的标志是控制台出现：

```text
旧物回收项目启动成功...
```

这个窗口不要关。关掉之后，管理端和用户端都会连不上。

也可以在 IDE 里运行 `sqx-application` 模块的 `com.sqx.SqxApplication`。看到同一句启动成功即可。

## 怎样算成功

浏览器打开：

http://127.0.0.1:9135/sqx_fast/doc.html

能看到接口文档，标题是「旧物回收系统接口文档」。页面上可以按「业务模块 - 管理端」「业务模块 - APP端」「系统模块」分组查看。这个页面是给开发看接口用的，不是给用户预约回收的页面。

## 常见问题

- 控制台报数据库拒绝连接：MySQL 没启动，或 `application-dev.yml` 的密码、端口和安装时不一致。
- 启动去连了 `shuju.xianmxkj.com`：`application.yml` 仍是 `prod`。改成 `dev` 后重新启动。
- 提示找不到 `java` 或 `mvn`：软件没加到 PATH，或开的是改 PATH 之前的旧窗口。关掉 PowerShell 再开一次。
- 端口 9135 已被占用：先停掉上一次启动的服务端窗口，或运行 `scripts/free-port-9135.ps1` 后再启动。
- 接口文档能开，但管理端登录说账号不存在：业务脚本已经导入，系统管理员表还是空的。这不是用户端页面打不开，而是后台账号还没准备好。
