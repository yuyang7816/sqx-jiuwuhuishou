# 用户端运行教程

按顺序做。这是给手机和网页用的应用，窗口标题是「旧物回收」。需要上门回收或寄件回收的人用它估价、下单；回收员登录后也可以在这里看取件任务。用 HBuilderX 打开 `jiuwuhuishou-user` 文件夹来运行。

先按 [服务端运行教程](服务端-运行教程.md) 导入 `jiuwuhuishou-server/sql` 并启动服务端。你要看自己电脑里的品类和订单时，还要把下面第 1 步的地址改到本机。服务端没启动、地址仍指向线上时，页面也许能打开，但看到的是线上数据，登录和本机后台对不上。

## 开始之前要准备什么

安装 HBuilderX：https://www.dcloud.io/hbuilderx.html

下载「正式版」。解压或安装后，打开软件，窗口标题是 HBuilderX，就说明安装成功。

只在电脑浏览器里看时，不需要微信开发者工具，也不需要先安装 Node.js。这个用户端目录里没有单独的 `package.json` 启动脚本，请用 HBuilderX 运行。要在微信里看，再安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

浏览器使用 Chrome 或 Edge。

## 第 1 步：确认连的是自己电脑上的服务端

用记事本打开 `jiuwuhuishou-user/common/config.js`。

文件里现在生效的是线上地址：

- 接口：`https://jwhs.xianmxkj.com/sqx_fast`
- 客服 WebSocket：`wss://jwhs.xianmxkj.com/wss/chatSocket/`

这表示：你用 HBuilderX 运行出来的页面，会去读线上体验站的品类、公告和订单。这样可以先看界面，但改不了你本机数据库里的内容，也登不进你本机新建的账号。

要改成本机，把正在生效的两行换成下面这样，原来的线上地址可以先注释掉：

- 接口地址：`http://127.0.0.1:9135/sqx_fast`
- WebSocket 地址：`ws://127.0.0.1:9135/sqx_fast/`

文件顶部已经有这两行的注释示例。服务端就装在你这台电脑上时，用 `127.0.0.1`。注释里的 `192.168.0.128` 是另一台电脑的例子。你把服务端端口改过，才把 `9135` 改成新端口，保存。

请注意：如果浏览器打开的网址是 `jwhs.xianmxkj.com`，页面会去连线上服务器，看不到你本机刚改的品类。练习时请用下面第 3 步打开的本机地址。

## 第 2 步：用 HBuilderX 打开项目

1. 打开 HBuilderX。
2. 菜单选「文件」→「打开目录」。有的版本也叫「从本地打开」。
3. 选中 `jiuwuhuishou-user` 这个文件夹。不要选它的上一级（那一层还有 `jiuwuhuishou-server` 和 `jiuwuhuishou-admin`），也不要只选里面的某个页面。
4. 左侧能看到 `pages`、`pages.json`、`manifest.json`、`common`。

左侧如果是空的，说明选错了文件夹，请重新选带 `pages.json` 的那一层。

## 第 3 步：在电脑浏览器里运行

1. 菜单选「运行」→「运行到浏览器」→「Chrome」。没有 Chrome 时选 Edge。
2. 第一次会下载编译器，底部控制台会出现「正在编译」。等到出现「编译成功」，浏览器会自己打开。第一次可能会提示安装浏览器运行插件，点允许或安装，等它装完再重新点一次运行。
3. 地址以控制台里打印的为准。`manifest.json` 里 H5 开发端口写的是 **8852**。如果控制台里写的是别的端口，用控制台里的地址。
4. 打开后顶部标题是「旧物回收」，底部应能看到 **首页、福利中心、订单、我的**。

HBuilderX 不要关。关掉后页面会打不开。

## 第 4 步：在微信小程序里运行（可选）

电脑浏览器已经能看，可以先不做这一步。

1. 安装并打开一次微信开发者工具，用微信扫码登录。
2. 在微信开发者工具里打开「设置」→「安全设置」，打开服务端口。
3. 回到 HBuilderX，菜单「工具」→「设置」→「运行配置」，把微信开发者工具的安装路径填上。
4. 菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」。

`manifest.json` 里微信小程序的 `appid` 现在是 `touristappid`。自己练习时，把它改成你自己的小程序 AppID，或继续只用浏览器运行。

微信开发者工具里如果提示域名不合法，本地调试可以勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。`127.0.0.1` 不是微信后台配置过的合法域名，不勾选这一项，模拟器里的接口会失败。

小程序里的微信登录，还要在管理端「系统配置」里填写你自己的小程序 AppId 和 Secret。只改 `manifest.json`、不填后台密钥时，授权手机号这一步会失败。

## 怎样算成功

首页能打开，底部四个按钮能点：首页、福利中心、订单、我的。按键盘 `F12`，点「网络」或 Network，再按一次浏览器的刷新。本机联调时，列表里的请求地址应是 `127.0.0.1:9135`。出现 `jwhs.xianmxkj.com`，说明 `common/config.js` 仍指向线上。

首页能看到轮播、品类入口（家电回收、数码回收、旧衣回收等）或成交公告，说明已经读到数据。一件品类都没有时，先确认服务端用的库是 `jiuwuhuishou`，并且 `sql` 已按版本导入，同时用户端地址已经改到本机。

点「福利中心」「订单」或「我的」时，如果跳到登录页，也算页面已经打开。这几页需要登录后才能看自己的积分、订单和钱包。

网页登录用手机号和密码。注册、找回密码要短信验证码。配置里 `sqx.verify-code.test-mode` 为 `true` 时，验证码固定填 **888888**，手机不会收到短信。正式发短信时，把测试模式关掉，并在管理端填好短信通道。

## 常见问题

- 首页一直转圈或是空的：服务端没启动，或 `config.js` 指向的地址不对。
- 打开的是线上体验站：地址栏是 `jwhs.xianmxkj.com`，或 `config.js` 仍是线上域名。
- 家电、数码页面能看，旧衣预约一点就去登录：旧衣、书籍、福利、订单和「我的」会先检查登录，这是当前页面的行为。
- 图片上传失败：服务端没启动，或管理端「系统配置」里把存储改成了阿里云但没填密钥。开源库默认把图片存在运行服务端的那台电脑上，类型保持「本地」即可。浏览器如果问能不能访问相册，点允许。
- 微信里授权登录失败：后台还没填你自己的小程序密钥。浏览器里可以先用手机号密码登录。
