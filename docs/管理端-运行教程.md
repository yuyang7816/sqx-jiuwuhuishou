# 管理端运行教程

按顺序做。这是电脑浏览器里的后台，不是手机应用。预约回收的用户不打开这个网站。代码在 `jiuwuhuishou-admin` 文件夹。打开后窗口标题是「旧物回收管理后台」。

先按 [服务端运行教程](服务端-运行教程.md) 把数据库导入并启动服务端。服务端窗口里要已经出现「旧物回收项目启动成功...」，并且那个窗口不能关。服务端没启动时，这个网站打得开，但验证码图片是裂的，登录也会失败。

## 开始之前要准备什么

安装 Node.js 18 或更高：https://nodejs.org/

建议装 18 或 20 的长期支持版。安装时勾选添加到 PATH。安装完成后，重新打开 PowerShell，输入：

```powershell
node -v
npm -v
```

两行都有版本号才算成功，例如 `v18` 或 `v20`，以及 `8.x` 以上。只看到「不是内部或外部命令」时，关掉窗口再开一次；还是没有，就重新安装 Node.js 并勾选 PATH。

浏览器使用 Chrome 或 Edge。

## 第 1 步：确认连的是自己电脑上的服务端

用编辑器打开 `jiuwuhuishou-admin/src/utils/tool.js`，找到 `getApiBaseUrl`。

现在真正生效的是函数里面写死的这一行：

```text
https://jwhsadmin.xianmxkj.com/sqx_fast/
```

本机练习时改成：

```text
http://127.0.0.1:9135/sqx_fast/
```

末尾的斜杠保留。你把服务端端口改过，才把 `9135` 改成新端口。

`.env.development` 里也有一条线上地址，当前这段函数没有读取它。只改 `.env`、不改 `tool.js`，页面仍会去连线上管理端，看不到你本机刚导入的订单和品类。

改完之后，如果管理端已经在运行，先在那个窗口按 `Ctrl + C` 停掉，再重新执行下面的 `npm run dev`。已经打开的页面要刷新一次。

## 第 2 步：安装依赖

在 `jiuwuhuishou-admin` 文件夹里打开 PowerShell（在文件夹空白处按住 Shift，右键，选「在此处打开 PowerShell 窗口」或「在终端中打开」），执行：

```powershell
npm install
```

第一次可能要几分钟到十几分钟。结束时没有红色 `npm ERR!`，并且这个文件夹里出现 `node_modules`，就成功了。

## 第 3 步：启动网站

还在这个文件夹里执行：

```powershell
npm run dev
```

等到控制台出现本地地址。开发端口是 **5176**，一般是：

http://127.0.0.1:5176/

用浏览器打开这一行。打不开时，用控制台里实际打印的地址。

这个窗口不要关。关掉后网页会变成无法访问。

## 第 4 步：登录

登录页要填账号、密码，还要看一张图片验证码。看不清就点图片换一张。验证码由服务端生成。

登录页源码注释里的演示账号是：

- 账号：`admin`
- 密码：`123456`

这和 MySQL 的 root 密码不是同一个。空库只导入了 `jiuwuhuishou-server/sql` 里的业务脚本时，这个管理员还不在库里，登录会失败。需要库里已经有对应的系统用户，才能进后台。

登录成功后，左侧应能看到「数据中心」。能看到哪些业务菜单，取决于这个账号被分配的权限。

## 怎样算成功

浏览器打开 `http://127.0.0.1:5176/`，登录页标题一带是「旧物回收管理后台」，验证码图片能显示。用已有的管理员账号登录后，能进入数据中心。

按 `F12` 打开网络面板，登录请求的地址应是 `127.0.0.1:9135`。如果仍是 `jwhsadmin.xianmxkj.com`，说明 `src/utils/tool.js` 还没改，或改完后没有重启 `npm run dev`。

## 常见问题

- 验证码图片裂开、登录一直转圈：服务端没启动，或 `tool.js` 仍指向线上。
- 页面能开，登录提示账号或密码错误：服务端已连通，但当前库里没有这个管理员。
- `npm` 不是内部命令：Node.js 没装好，或 PATH 还没生效。重新打开 PowerShell。
- 5176 端口被占用：关掉上一次的管理端窗口，再执行 `npm run dev`。
