# 用户端功能说明

用户端是预约旧物回收的人在手机或电脑网页里打开的那个应用。窗口标题是「旧物回收」。底部一直有四个按钮：**首页、福利中心、订单、我的**。

同一套应用里还有回收员用的取件入口。员工账号登录后，「我的」底部会出现「我的取件」。平台工作人员不使用这个应用。上架品类、改价格、审打款、填支付密钥，在电脑上的管理端做。

下面按「打开后能点到什么」来写。每一处都说明：点进去做什么，以及会不会真的连到微信、支付宝、短信、顺丰这些外面的服务。

## 这个端是给谁用的

- **用户**：看家电、数码、旧衣、奢侈品、书籍的回收价，选上门或寄件，提交订单，看结算和打款，签到领积分，邀请好友拿佣金。
- **回收员**：查看分配给自己的取件任务，开始上门，完成后回填实际成交金额，并可以给用户打电话。
- **还没登录的人**：可以看首页、家电估价、数码和奢侈品搜索、回收规则。一点旧衣预约、福利中心、订单、钱包，就会去登录。

没有单独再装一个「回收员 App」。分配任务、审核打款在管理端完成，用户和回收员在这里看进度。

## 首页

打开就是首页。

- **顶部品牌**：名称是「旧物回收」。
- **推送提醒条**：文案以后台配置为准，例如回收进度提醒。可以点「立即开启」，也可以关掉这一条。
- **轮播图**：后台配置的广告。例如旧衣回收。点某一张，会按后台设置跳到对应页面。库里没配图时，这一块可能是色块或空的。
- **成交公告**：滚动展示近期回收成交，例如某位用户刚刚回收旧衣获得多少钱。
- **品类入口**：常见是家电回收、数码回收、旧衣回收、奢侈品、书籍。名字和跳转以后台品类配置为准。
- **推荐赚钱**：引导去分佣说明或邀请页。文案类似「每邀请一位好友，立得现金」。
- **任务入口**：每日签到、环保红包、品牌合作、家电维修等。具体有哪几个，以后台配置为准。
- **在线客服**：右下角入口。真正聊天要先登录。

下拉可以刷新。这些内容来自你导入的数据库，或你在管理端改过的数据。服务端没启动时，这里会一直转圈或是空的。地址仍指向线上体验站时，看到的是线上数据，不是你本机后台刚改的那一条。

## 家电回收

从首页「家电回收」进去。

- 先看流程说明：线上预约、电话沟通、上门回收、立即收钱。
- 再选品类，例如空调、冰箱、洗衣机、电视。
- 选品牌和型号，按成色等参数看预估区间。页面上的价格是参考价，最终以质检或上门确认为准。
- **马上预估回收**：进入估价结算。可选上门回收或顺丰寄件。上门要选服务城市、取件地址和时段。
- **回收规则**：可再打开计价标准、超远距离费等说明。

只看价格不需要微信或支付宝。真正提交订单一般要先登录。

## 数码和奢侈品

从首页「数码回收」或「奢侈品」进去。

- **搜索机型 / 搜索奢侈品**：可以搜品牌、机型或品类，也可以点热门搜索、历史记录，或按品牌找。
- 点进一个型号后选规格，按参数估出参考价，再进入结算。
- 结算时同样要选地址和履约方式。没登录会先去登录。

热门词和品牌来自后台品类主数据。库里如果还有「默认型号」这类占位数据，页面上也会照实显示。

## 旧衣和书籍

从首页「旧衣回收」或「书籍」进去。这两页在打开时就会检查登录，没登录会先到登录页。

登录之后可以：

- 看可回收品类和单价，例如上衣裤子、床单毛毯，或书籍重量档位。
- 选常用地址。没有地址时先新增，填写联系人、电话、省市区和详细地址。
- 选预约时段和预估重量，看预估金额。
- 提交后进入下单成功页，可以再分享邀请。

价格和可约天数以后台「回收配置」为准。

## 上门回收和顺丰寄件

家电等品类在估价结算里选履约方式：

- **上门回收**：选服务城市、取件地址、上门时段后提交。订单里可以联系回收员。
- **顺丰寄件**：按平台收件信息寄出。页面上的包邮说明以当时配置为准。寄出后可在订单里看快递公司和运单号。物流轨迹要后台配好顺丰或物流查询密钥，才会向外面的快递服务查询。没配密钥时，运单号可以记下来，轨迹可能是空的。

下单成功不代表钱已经到账。成交价要等质检或上门确认，再走结算和打款。

## 福利中心

底部「福利中心」。没登录会先去登录。

- 看我的金币、连续签到天数。
- **每日签到**领金币。连续签到奖励可以按后台开关出现或隐藏。
- 做福利任务，例如邀请好友、发布回收。任务名称以后台「福利任务」为准。
- 积分可按规则兑到钱包。兑换比例在后台配置，不是写死在页面上的。

签到和兑换只改自己数据库里的积分和余额，不经过微信或支付宝。

## 订单

底部「订单」。没登录会先去登录。登录后按状态筛选：**全部、进行中、待确认、已完成**。

点进一单可以看到：

- 订单状态、订单编号、回收品类。
- 履约方式是上门还是邮寄，以及预约时间、地址。
- 预估金额和实际成交金额。
- 服务进度时间线。
- 邮寄单的快递公司、运单号。需要时补填发货信息。

进行中可以改约、异常反馈、取消订单。上门单可以「联系回收员」，这会调用手机拨号，不经过支付。

待确认时进入「结算确认」：接受成交价，或发起价格争议。完成后可以评价，并查看「打款进度」。打款进入的是平台钱包，不是下单当时就转到微信。

## 我的：钱包、会员、邀请

底部「我的」。没登录会先看到登录页。

- **登录**：网页用手机号和密码。注册、找回密码要短信验证码。`sqx.verify-code.test-mode` 为 `true` 时，验证码固定是 `888888`，不会发到手机。微信小程序里可以先微信授权，再授权手机号。登录前要同意《用户协议》《隐私政策》。
- **资料**：改头像、昵称。头像从手机相册选，浏览器会问是否允许访问相册。
- **常用地址**：新增或编辑上门、取件地址，可标家或公司，也可设默认。
- **账户余额**：看余额、预估待入账、环保积分，以及余额明细。
- **提现**：申请提到微信收款码或支付宝账号。提交后等后台审核。没配支付密钥时，申请可以记下来，钱不会自动打到微信或支付宝。
- **会员中心**：看优先上门、专属客服、加价回收等权益，选套餐后付款。微信支付一般只在微信小程序或微信内打开的页面里出现。普通电脑浏览器通常走不到微信支付。
- **我的推荐 / 邀请好友**：生成邀请海报和链接，看邀请记录和分佣说明。佣金可提现到钱包。保存海报时，浏览器或手机可能要求相册权限。
- **帮助 / 客服**：看常见问题，登录后可进在线客服发消息。
- **系统设置**：消息通知开关、修改密码、清理缓存、关于我们、协议、退出登录。
- **品牌合作**：提交品牌合作意向，字段以后台和页面配置为准。

## 回收员能做什么

员工账号由后台分配，用户端没有公开的入驻申请。

员工登录后，「我的」会出现「我的取件」：

- **今日取件任务**：按待上门、取件中、已完成查看数量和列表。
- **取件详情**：看回收品类、联系人、预约时间、取件地址和流程。
- **开始上门 / 确认完成**：按任务状态推进。完成时回填实际成交金额，作为用户侧成交和后续打款的依据。
- **联系用户**：拨打电话确认地址和时间。

普通用户看不到「我的取件」。

## 哪些事会连到外面的服务

| 你在页面上做的事 | 没配密钥时 | 配好密钥之后 |
|---|---|---|
| 看首页、品类、规则、预估价 | 只读自己的数据库 | 仍然只读自己的数据库 |
| 注册、找回密码的短信 | 测试模式开着时，验证码是 `888888`，不发短信 | 测试模式关掉后，按短信宝、阿里云或腾讯云真正发送 |
| 微信一键登录、微信支付、提到微信 | 按钮可能在，点了完不成授权或付款 | 用你自己的小程序和商户号 |
| 提到支付宝 | 可以记下账号，不会自动打款 | 按支付宝通道处理 |
| 顺丰寄件、物流轨迹 | 可以记运单号，轨迹可能为空 | 向顺丰或物流查询服务取轨迹 |
| 在线客服 | 消息存在自己的库里，双方都连着本服务端就能聊 | 不经过第三方客服公司 |
| 拨打回收员或用户电话 | 调用手机拨号 | 不经过平台支付 |

密钥在管理端「系统配置」里填写。体验地址 [https://jwhs.xianmxkj.com](https://jwhs.xianmxkj.com) 看的是线上数据，和你本机导入的库不是同一份。
